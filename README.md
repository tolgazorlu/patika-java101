# patika-java101

Standalone Java exercises from the Patika.dev Java 101 course.

## About

Each file is an independent practice program covering basic Java syntax,
loops, and simple algorithms. Built March 2023 as course work.

## Features

- Loop and conditional practice (`while-practice1/2/3.java`, `artik-yil.java`)
- Math and number problems (`fibonacci.java`, `asal-sayi.java`,
  `perfect-number.java`, `armstrong.java`, `ebob-ekok.java`, `exponent.java`,
  `combination.java`, `harmonic.java`)
- Small calculators (`hesap-makinesi.java`, `taksimetre.java`,
  `daire-alan-cevre.java`, `vucut-kitle-indeksi.java`, `kdv-tutar.java`,
  `not-ortalama.java`, `manav-kasa.java`, `atm.java`)
- Misc practice (`diamond.java`, `ters-ucgen.java`, `max-min.java`,
  `number-sort.java`, `user-input.java`, `lesson-pass.java`,
  `horoscope.java`, `cin-zodyagi.java`, `flight-ticket.java`,
  `activity-suggestion.java`)
- OOP homework diagram (`oop-odev1.drawio.png`)

## Tech stack

- Java

## Getting started

Each `.java` file is self-contained:

```bash
javac <file>.java
java <ClassName>
```
